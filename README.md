# Проект: Руководство по Space Station 13 Colonial Marines (PVE)

Этот файл служит отправной точкой для понимания структуры и целей проекта. Предназначен для разработчиков и AI-ассистентов.

## Описание Проекта
Проект представляет собой руководство для новичков по игре **Space Station 13**, а именно для режима/сервера **Colonial Marines** с упором на **PVE** (Player vs Environment).

**Язык проекта:** Русский

## Основные Принципы
1.  **Целевая Аудитория:** Новички, желающие разобраться в механиках.
2.  **Язык:** Вся документация и контент ведутся на русском языке.
3.  **Формат:** Статический сайт (MkDocs).

## Технический Стек
*   **Движок:** [MkDocs](https://www.mkdocs.org/)
*   **Тема:** [Material for MkDocs](https://squidfunk.github.io/mkdocs-material/)
*   **Плагины:** `mkdocs-glightbox` (Zoom изображений)
*   **Кастомизация:** `extra.css` (Стили), `header_link.js` (Фикс шапки)

## Структура Проекта
*   `mkdocs.yml` - Конфигурация.
*   `docs/`
    *   `index.md` - Главная страница (Лендинг).
    *   `guides/` - Руководства (Вход на сервер и т.д.).
    *   `lore.md` - Лор и структура.
    *   `mechanics/` - Механики и роли.
    *   `faq.md` - Частые вопросы.
    *   `stylesheets/` - Кастомные стили.
    *   `javascripts/` - Скрипты.

## Сборка и Просмотр (Локально)

### Windows (Рекомендуется)
Используйте готовые `.bat` файлы в корне папки:
1.  **`run_local.bat`**: Собирает сайт и запускает локальный сервер. Открывает доступ по адресу `http://127.0.0.1:8000`.
2.  **`build.bat`**: Просто собирает сайт в папку `site/`.

### Вручную (CLI)
1.  **Установка**:
    ```bash
    pip install mkdocs-material mkdocs-glightbox
    ```
2.  **Запуск**:
    ```bash
    mkdocs serve
    ```

## Оформление Контента (Style Guide)

### Изображения и Подписи
Для изображений мы используем специальный класс `.caption`, чтобы подписи выглядели красиво (по центру, серым курсивом).

**Правильный формат:**
```markdown
![Описание картинки](img/image.png)
*Текст подписи*{: .caption }
```
*Важно: Не забывайте добавлять `{: .caption }` к тексту подписи!*

### Ссылки
*   Внутренние ссылки должны быть относительными: `[Текст](guides/server_enter.md)`.

### Блоки (Admonitions)
Используйте их для важных заметок:
```markdown
!!! note "Заметка"
    Текст заметки.

!!! warning "Внимание"
    Важное предупреждение.
```

## Особенности Темы USCM
*   **Light Mode**: Цветовая схема "Гарнизон" (Blue-Grey / Teal).
*   **Dark Mode**: Цветовая схема "Тактическая" (Slate / Green).
*   **Navigation**: Меню на русском языке, настроено вручную в `mkdocs.yml`.
*   **Pretty URLs**: Адреса страниц не содержат `.html`.
